# Migration Hub — UX Writing Portfolio

A minimalist, white-background UX writing case study designed for GitHub Pages.

## What this demonstrates

- UX writing and content design
- AI-assisted enterprise product experiences
- Onboarding and progress communication
- Administrative UX and terminology systems
- Support-form microcopy
- Error writing and recovery
- Content design principles and systems thinking

## Publish with GitHub Pages

1. Create a new GitHub repository, for example:
   `migration-hub-ux-writing-portfolio`
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will generate your public portfolio URL.

## Before sharing

Replace `your-email@example.com` in `index.html` with your preferred contact email.

The case study intentionally uses the fictionalized product name **Migration Hub** and genericized visuals/content for external portfolio presentation.

## Files

- `index.html` — portfolio page
- `styles.css` — visual design and responsive layout
- `script.js` — subtle scroll-reveal interaction
- `assets/` — final portfolio screenshots
